# Evaluation result operations

- **Publish a local result:** From the connected workspace, run `osmosis --json eval upload <run-name-or-directory>` only when publication is requested. CLI 0.3.10 requires that working directory even with an absolute result path and root `--workspace`. The command sends dataset rows, logs, trajectories, and artifacts without a confirmation prompt; review sensitive outputs first. Failed or skipped items can be terminal; pending or cancelled runs cannot be uploaded. An interrupted upload can resume against the same result. Its platform origin stays local; it proves neither Git sync nor hosted execution.
- **Retry locally:** rerun the original `eval run` with unchanged inputs, including any local dataset override, plus `--name <run-name> --retry-failed`. It preserves successes and retries failed and skipped items; locally skipped items can include deliberate grader exclusions. Republish with `eval upload <run-name> --replace` only when replacement is intended.
- **Retry on the platform:** `osmosis --json eval retry <run-name> --yes` starts work for eligible failed/skipped samples without rerolling graded rewards. Verify the cause and authorization for the additional work. Resupply any transient secrets through the supported secret input, never in chat or command arguments. Changed inputs need a new evaluation.
- **Stop:** `osmosis --json eval stop <run-name> --yes` stops a managed run only when that target is authorized. Stop a local run through its local runner.
